## 📌 Descripción General
Este repositorio reúne los proyectos, desarrollos computacionales y pipelines analíticos desarrollados durante la **Diplomatura en Ciencia de Datos e IA aplicada a la Salud** (Universidad Nacional de Córdoba). 

El objetivo principal es aplicar técnicas cuantitativas avanzadas, Machine Learning, Deep Learning y NLP a problemas del sector biomédico, biotecnológico y clínico, manteniendo altos estándares de reproducibilidad y ética en el manejo de datos en salud.
